# NEON BEAT

브라우저에서 실행하는 오리지널 4레인 리듬 게임 프로토타입입니다. 별도 빌드 도구나 설치가 필요하지 않습니다.

## 실행 방법
- 저장소의 `index.html`을 브라우저에서 열면 실행됩니다.
- GitHub Pages를 켜면 웹사이트 주소로 접속할 수 있습니다.
- GitHub 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택하고 `main` / `/(root)`를 지정한 뒤 Save를 누르세요.

## 조작
- 기본 키: ← ↓ ↑ →
- 우측 상단 설정(⚙)에서 각 레인의 키를 변경할 수 있습니다.
- 노트가 판정선에 도달할 때 해당 키를 누르세요.
- ESC 또는 일시정지 버튼으로 게임을 멈출 수 있습니다.

## 포함 기능
- 4레인 리듬 플레이 및 4단계 난이도
- 오리지널 데모 트랙 3개와 브라우저 합성 타격음
- PERFECT / GOOD / MISS 판정, 점수, 콤보, 정확도
- 피버 게이지 및 노트 스킨 3종
- 키 설정 및 최고 점수의 브라우저 로컬 저장
- 간단한 채보 작성 및 JSON 복사

## 참고
이 프로젝트는 독자적인 디자인과 데모 패턴을 사용합니다. 실제 음원 파일은 포함하지 않습니다. 커스텀 곡을 추가할 때는 사용 권한이 있는 음원과 직접 제작한 채보를 사용하세요. 기록은 현재 브라우저의 localStorage에 저장되므로 다른 기기와 자동 동기화되지 않습니다.
